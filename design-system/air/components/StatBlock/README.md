# StatBlock

Indicador numérico: o número em mono grande e uma legenda curta em minúsculas logo abaixo.

**O consumidor fornece:** o valor (com sufixos como "+", "x", "#") e a legenda.

- Faixa de indicadores: números `mono-figure` com legenda `mono-body`, alinhados pela base, com 120px entre eles, numa faixa branca abaixo de uma metade superior escura.
- Destaque: números `mono-hero` com legenda `body`, sobre foto escurecida.
- Abra a faixa com uma frase `mono-body` cujo início vai em negrito.
