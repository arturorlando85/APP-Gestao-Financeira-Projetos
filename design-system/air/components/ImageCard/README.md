# ImageCard

Card cinza com uma foto aprovada no topo e uma linha de texto com seta abaixo; usado em pares.

**O consumidor fornece:** uma imagem aprovada e uma frase curta.

- Fundo `gray-250`, foto reta de 216px de altura a `space-card-pad` das bordas, texto `body` preto com `arrow-black.svg`.
- Dois cards lado a lado com `space-card-gap`; mantenha a metade direita do slide livre.
- Imagens precisam de aprovação de Comms/Marketing (veja Backgrounds).
