# NotchTable

Tabela de colunas ou linhas cujos cabeçalhos têm o canto superior direito cortado, a assinatura formal da marca.

**O consumidor fornece:** títulos de coluna/linha e o conteúdo das células.

- Variante escura: cabeçalho branco `mono-small` preto com `notch-header`, células `gray-450` e `gray-650` alternadas por coluna, texto `lead` branco com seta.
- Variante clara: barra `gray-400` com título `mono-tag` branco e `notch-header`, seguida de três células `gray-050` com texto `body-sm` preto, separadas por 4px.
- Ao lado, um painel `gray-500` com título `title-sm` branco resume a tabela.
