# ArrowList

Lista vertical em que cada item começa com a seta ↗; é o marcador padrão da marca.

**O consumidor fornece:** de 3 a 5 itens curtos.

- Itens em `mono-body` (lista técnica) ou `lead` (lista de frases), com 28–46px entre itens e 40px entre seta e texto.
- Seta preta em fundo claro, branca em fundo escuro ou foto.
- Não use bullets, números ou outros ícones.
