# Card

Bloco reto cinza com título em mono e uma linha de texto iniciada pela seta; aparece sempre em grade, com tons diferentes por card.

**O consumidor fornece:** título curto (`mono-tag`), texto (`body-sm`) e o tom da rampa de cada card.

- Classes de tom `air-card--050` … `air-card--700` (de `gray-050` a `gray-700`). Texto preto até `gray-300`; branco de `gray-400` para baixo (no `gray-400`, branco só em 24px ou mais).
- Grade com `space-tile-gap`; respiro interno `space-card-pad`.
- Distribua os tons em degradê (claro → escuro) ou alternando duas colunas; não repita o mesmo cinza em todos.
- Funciona sobre fundo branco, foto desfocada ou `surface-graphite`.
