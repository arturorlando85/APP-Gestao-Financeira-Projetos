# BarList

Lista de frases em que cada item é marcado por uma barra vertical branca de 6px, usada no slide escuro sólido.

**O consumidor fornece:** 3 a 5 frases curtas.

- Fundo `surface-carbon` (#222222), texto `lead` branco, barra de 6px × 96px em `ink`.
- Combine com a seta gigante decorativa em `gray-650` atrás do título e um bloco `gray-400` acima da lista.
