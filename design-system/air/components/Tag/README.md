# Tag

Etiqueta cinza retangular com o canto superior direito cortado, em mono, usada em nuvens de tags de largura variável.

**O consumidor fornece:** o texto curto e, opcionalmente, a seta à esquerda.

- Fundo `card` (#d3d3d3 no claro, #646464 no escuro), texto `card-ink`, corte `notch-tag`.
- Duas variantes do template: com seta (`mono-tag`, altura 68px, alinhada à esquerda) e centralizada sem seta (`mono-small`, altura 83px).
- Monte linhas de larguras **desiguais** com `space-tag-gap` entre tags e entre linhas; a última linha pode ser mais curta. Larguras iguais parecem tabela, não nuvem.
