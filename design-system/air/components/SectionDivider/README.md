# SectionDivider

Slide de abertura de seção: uma foto aprovada em tela cheia, escurecida, com a seta branca pequena no terço inferior direito e nenhum texto.

**O consumidor fornece:** uma das imagens `section-*.jpg` do grupo Backgrounds.

- Use apenas `section-portrait-screen.jpg`, `section-abstract-blocks.jpg`, `section-smiling-colleague.jpg` ou `section-hands-circuit.jpg`.
- Seta `arrow-white.svg` de 36px em x=1466, y=812.
- Sem título, logo nem cabeçalho neste slide.
